# 改掉斗鱼各种烦人的地方

## 简介

一个用于电脑端斗鱼网页版的油猴脚本，去掉观看直播时不需要的干扰。各项功能都可以单独开启或关闭，设置会自动保留。

## 功能

以下功能默认开启：

- **去掉斗鱼的刀塔助手**：鼠标移到视频中的英雄、技能或装备上时，不再弹出助手，同时去掉助手入口和提示窗。主播战绩面板和第一视角入口不受影响。
- **关注页轮播主播显示为未开播**：轮播主播显示与未开播主播相同的遮罩、上次直播时间或停播预告，不再显示轮播标记和悬停视频预览。主播仍保留在关注列表中，正常直播照常显示。

## 安装方法

1. 在电脑浏览器中安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击 [安装脚本](https://raw.githubusercontent.com/KNaiFen/douyu-tweaks/main/douyu-tweaks.user.js)，在弹出的油猴页面确认安装。
3. 刷新已打开的斗鱼页面，即可使用。

如果安装链接只显示代码，可从 [版本下载页](https://github.com/KNaiFen/douyu-tweaks/releases/latest) 下载 `.user.js` 文件，再通过油猴的导入功能安装。

## 功能设置

打开斗鱼页面，点击浏览器工具栏中的油猴图标，在“改掉斗鱼各种烦人的地方”下选择 **设置**。勾选需要的功能，点击 **保存并刷新** 即可生效；取消勾选可恢复对应的斗鱼原有功能。其他已打开的斗鱼页面也需要刷新。

## 更新与停用

在油猴管理面板中可以检查更新、停用或删除脚本，操作后刷新斗鱼页面即可。

遇到问题可先停用脚本，再到 [问题反馈](https://github.com/KNaiFen/douyu-tweaks/issues) 描述现象和操作步骤，请勿附带个人信息。
