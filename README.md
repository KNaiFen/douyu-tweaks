# 改掉斗鱼各种烦人的地方

按自己的习惯，关掉斗鱼直播中烦人的功能。每项功能都可以在设置里单独开启或关闭。

适用于电脑浏览器中的斗鱼网页版，需要安装 Tampermonkey（油猴）。

## 安装

1. 在桌面浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 [安装脚本](https://raw.githubusercontent.com/KNaiFen/douyu-tweaks/main/douyu-tweaks.user.js)，在 Tampermonkey 页面确认安装。
3. **刷新已打开的斗鱼页面**。

若链接未弹出安装页面，可下载仓库中的 `douyu-tweaks.user.js`，通过 Tampermonkey 的导入功能安装。

## 使用

1. 打开斗鱼页面，点击浏览器工具栏中的 Tampermonkey 图标。
2. 在“改掉斗鱼各种烦人的地方”下面点击 **设置**。
3. 勾选要开启的功能，取消勾选则关闭该功能。
4. 点击 **保存并刷新**，页面刷新后应用设置。点击“取消”或按 Esc 放弃修改。

设置会保留，下次打开斗鱼继续使用。其他已打开的斗鱼页面需要刷新后应用新设置。

## 当前功能

**去掉斗鱼的刀塔助手**：默认开启。鼠标移到视频中的英雄、技能或装备上时，不再弹出刀塔助手，同时去掉“刀塔助手”入口和提示窗。关闭此项并保存刷新后恢复原来的助手功能。

主播战绩面板和第一视角入口不在本脚本的屏蔽范围内。

**关注页轮播主播显示为未开播**：默认开启。在“我的关注”页面，轮播主播使用和未开播主播一样的卡片，显示遮罩和上次直播时间；主播设置了停播预告时，会和普通未开播卡片一样显示预告。去掉“轮播”标记，鼠标移上去也不会播放轮播预览。正常直播的主播照常显示，主播仍保留在关注列表中。

在设置中关闭此项并保存刷新，可恢复斗鱼原来的轮播卡片。

## 更新与停用

- **更新**：在 Tampermonkey 管理面板中检查脚本更新，更新后刷新斗鱼页面。
- **暂时停用**：在 Tampermonkey 中关闭“改掉斗鱼各种烦人的地方”，然后刷新页面。
- **卸载**：在 Tampermonkey 管理面板中删除此脚本，然后刷新页面。

## 常见问题

### 安装后仍然弹出刀塔助手

确认 Tampermonkey 和本脚本都已启用，并允许 Tampermonkey 在斗鱼网站运行。在本脚本“设置”中勾选“去掉斗鱼的刀塔助手”，保存并刷新。如果仍未生效，先检查脚本是否有更新。

### 点击安装链接后只看到代码

可以从 [版本下载页](https://github.com/KNaiFen/douyu-tweaks/releases/latest) 下载 `.user.js` 文件，再通过 Tampermonkey 的导入功能安装。

### 更新后失效，或者影响了正常观看

先停用脚本并刷新页面。可以到 [问题反馈](https://github.com/KNaiFen/douyu-tweaks/issues) 提供浏览器名称、脚本版本和出现问题的操作步骤。截图前请遮住个人信息，不要上传 Cookie、账号凭据或完整网页存档。
